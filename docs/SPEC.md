# Đặc tả yêu cầu - DC Power (OWON SPM3103)

## Bố cục cửa sổ chính
```
┌───────────────────────────────┬──────────────┐
│                               │  Số V / A    │
│   Đồ thị V & A                │  (Set/Thực)  │
│   (2/3 rộng, 1/2 cao)         ├──────────────┤
│                               │  Set V, A,   │
│                               │  Vlimit,Alim │
├───────────────────────────────┼──────────────┤
│   Đồng hồ kim + số ở giữa     │  Chọn thang  │
│   (DMM)                       │  DCV,Diode,  │
│                               │  C, R...     │
└───────────────────────────────┴──────────────┘
 Thanh trên: [Kết nối]  [Output ON/OFF]
```

## 1. Nguồn DC
- [ ] Đồ thị V và A rõ ràng, tốc độ cập nhật nhanh nhất có thể; chiếm 1/2 cao, 2/3 rộng
- [ ] Số chính xác V, A (giá trị set và thực tế) ở cạnh đồ thị, phía trên
- [ ] Ô set V, A, V limit, A limit nằm dưới phần số
- [ ] Người dùng tự bố trí, thay đổi kích thước các thành phần

## 2. Cửa sổ
- [ ] Thay đổi kích thước cửa sổ chính
- [ ] Thay đổi hình nền
- [ ] Logo riêng (thư mục upload/)

## 3. Đồng hồ vạn năng (1/2 dưới)
- [ ] Trái: đồng hồ kim kèm số ở giữa
- [ ] Phải: chọn chức năng / thang đo (DCV, Diode, C, R, range...)
- [ ] Ghi lại giá trị đo

## 4. Điều khiển
- [ ] Nút kết nối
- [ ] Nút Output ON/OFF

## 5. Bổ sung (chờ xác nhận)
_(xem đề xuất)_
